# E-commerce Sales Dashboard

## Project Overview

This project presents an interactive Excel dashboard designed to explore e-commerce sales performance and product and operational metrics.

## Dashboards

- **Sales Overview:** A dashboard for exploring sales performance.
- **Product & Operations:** A dashboard focused on product and operational analysis.

## Tools & Skills

- Microsoft Excel / WPS Office
- PivotTables and PivotCharts
- Data visualization
- Interactive slicers and filtering
- Business data analysis

## Project File

Open `Ecommerce_Sales_Dashboard.xlsx` to explore the dashboard and its available filters.

## Purpose

The goal of this project is to practice data analysis, transform data into visual insights, and present business information in an accessible dashboard format.
